# Kasir Toko Android

Aplikasi Android WebView untuk website Kasir Toko di https://ojeteka.my.id/kasir_toko/.

Fitur utama:
- Login dan session web dipertahankan melalui cookie WebView.
- JavaScript dan DOM storage aktif.
- Upload file melalui file chooser Android.
- Download file melalui Download Manager.
- Tombol Back mengikuti riwayat halaman web.
- Link non-HTTP/HTTPS dibuka melalui aplikasi Android terkait.
- `window.print()` diarahkan ke dialog cetak Android.

Build APK otomatis tersedia melalui GitHub Actions.
